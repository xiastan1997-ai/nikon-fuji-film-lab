## 缺失项及影响

| 缺失 | 影响 | 下一动作 |
|---|---|---|
| 可用的 NX Studio 与机内文件导出 | Adobe DNG 路线已打通照片 RAW 像素；当前 NX Studio 1.11.0 要求 Windows 11，本机为 Windows 10 | 在符合官方要求的环境里创建/回读 Flexible Color NP3，再由用户 Z6III 导入实拍 |
| 颜色输入和曝光标定 | sRGB 中间空间会带来色域剪裁；手动 +2 EV 是实验显示选择，不是原厂照片匹配 | 增加可测量的白平衡/灰卡或同场景基准，确认场景线性到 F-Gamut C 的曝光与色彩映射 |
| NN 和理光目标样本 | CC、NC 有官方 LUT；理光官方有 IIIx 正/负片定性成对示例，但缺 GR III 默认设置的可标定文件 | 收集固定机型与设置的原机样本；不足时保留实验状态 |
| 真机导入与拍摄行为 | 按用户要求以最新 C 2.01 研发；已生成诊断 NP3，但用户设备实际版本和文件导入结果尚未知 | 先测试诊断包中性与饱和度两个文件，再测其余参数 |
| 五款目标 | 已确定 NC、NN、CC、理光 GR III 正片、负片 | 每款独立验收，不把 CC/NC 的官方 LUT 证据外推到其他三款 |
| 指定富士相机的同场景样本 | 不能验证“原机外观一致” | 后续有条件再采集；不阻断 LUT 数学参考 |
| NX Studio 可执行位置和版本 | NP3 导出/回读未就绪 | 确认实际安装及版本 |
