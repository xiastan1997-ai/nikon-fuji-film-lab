# 官方 CC/NC LUT 的输入与输出契约

来源：[Fujifilm GFX ETERNA 55 LUT 下载页](https://www.fujifilm-x.com/global/support/download/lut/)所附白皮书 1.01，第 11–13 页。本项目保留原 PDF 与 ZIP 的本地私有副本，不在 GitHub 再分发。

本项目检查的是 ZIP 内 `F-Log2C` 文件夹的 65 网格 `CLASSIC-CHROME` 与 `CLASSIC-Neg.` CUBE。文件名中的 `BT.709` 表示输出方向；白皮书推荐以 Rec.709、D65、Gamma 2.2 监看。输入必须先成为 **F-Gamut C 原色、F-Log2C 编码**的数值，不能把普通 Nikon JPEG 或未经色域处理的 NEF 数值直接送入 LUT。

白皮书第 11 页给出的 F-Log2C 编码，以场景线性反射率 `x` 为输入：

```text
x >= 0.000889: y = 0.245281 * log10(5.555556*x + 0.064829) + 0.384316
x <  0.000889: y = 8.799461*x + 0.092864
```

第 12 页给出 F-Gamut C 的色度坐标：R `(0.73470, 0.26530)`、G `(0.02630, 0.97370)`、B `(0.11730, -0.02240)`、白点 D65 `(0.31270, 0.32900)`。这里只抄录公开参数，不代表 Nikon RAW 已有可信的传感器到 F-Gamut C 变换。

当前 `tools/render_official_swatch.py` 用**人为指定的 F-Gamut C 场景线性 RGB 色块**走上式，再经 CUBE 采样。该图检验文件能读、通道顺序与插值可运算；不包含 Nikon RAW 显影、白平衡标定、曝光基准、光谱响应或画面局部处理。实际照片链必须先解决这些项，才能声称准确移植。
