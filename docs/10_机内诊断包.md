兼容目标按用户要求取最新官方版本：[尼康下载中心](https://downloadcenter.nikonimglib.com/en/products/629/Z6III.html)当前列出 Z6III C 2.01，发布日 2026-10-14。用户相机实际版本仍未知；这里记录的是研发目标，未执行相机升级。

## 这次可以拿到什么

本地 `outputs/calibration-z6iii-c201.zip` 内有 9 个 `.NP3` 诊断文件，按卡目录排好。它们用于测试 NP3 导入、参数响应和后续颜色拟合，**不是 NC/NN/CC/理光正负片成品**。

首次建议使用更小的 `outputs/z6iii-first-import-test.zip`，只含前两个文件和中文步骤，避免一次导入全部配置。

| 文件 | 相机显示名称 | 用途 |
|---|---|---|
| PICCON01.NP3 | LAB_NEUTRAL | 中性参数基准 |
| PICCON02.NP3 | LAB_SAT_P20 | 在基准上仅将饱和度增加 20 |
| PICCON03.NP3 | LAB_CON_P20 | 仅将对比度增加 20 |
| PICCON04.NP3 | LAB_BLUE_H20 | 仅将蓝色色相增加 20 |
| PICCON05.NP3 | LAB_BLUE_Cm20 | 仅将蓝色色度降低 20 |
| PICCON06.NP3 | LAB_BLUE_B20 | 仅将蓝色亮度增加 20 |
| PICCON07.NP3 | LAB_HI_WARM | 高光色彩分级：45°、色度 10 |
| PICCON08.NP3 | LAB_SH_COOL | 阴影色彩分级：220°、色度 10 |
| PICCON09.NP3 | LAB_CURVE_ID | 中性参数加恒等曲线，测试曲线文件结构 |

## 第一次只试前两个

1. 解压 ZIP，把里面的 `NIKON` 文件夹合并到相机存储卡根目录，最终路径为 `NIKON/CUSTOMPC/PICCON01.NP3` 等。如果卡上已有同名文件，先将原文件备份到电脑，避免覆盖。
2. 将卡放入相机菜单指定的**主插槽**。打开“照片拍摄菜单 → 管理优化校准 → 载入/保存 → 复制到照相机”。只选 PICCON01、PICCON02，分别保存到两个空的 C 槽位；保留原有常用配置。
3. 用相同的白平衡、曝光、SDR 模式，对蓝天/绿叶/彩色物体各拍一组 RAW+JPEG，先用 LAB_NEUTRAL，再用 LAB_SAT_P20。先判断两个文件是否能识别、是否能导入、能否正常拍摄，以及饱和度变化是否明显。
4. 若文件不显示或导入失败，记录相机固件版本、卡所在主插槽和屏幕提示。这个结果用于修正文件兼容性，不应靠刷改固件解决。

## 已验证与尚未验证

使用 [ssssota 的 MIT 许可 NP3 库](https://github.com/ssssota/nikon-flexible-color-picture-control)，固定提交 `ed0397fbf1e4d4f2bc11ab3070522c613667d359`。许可和原始源码保存在 `third_party/`。28 个上游测试全部通过，包括读回及与样本逐字节一致的写出。九个诊断文件均通过独立的文件头/基础条目长度检查、参数读回和二进制往返一致检查；单独修改蓝色色相只改变一个参数字节。

这些检查尚不证明 NX Studio 或 Z6III 会接受文件，也不证明相机内部色彩算法与电脑模型一致。文件清单及 SHA-256 在包内 `manifest.json`。源码配置为 `configs/lab-calibration.json`，可复现：

```powershell
node --experimental-strip-types tools/np3_tool.mjs build-lab
node --experimental-strip-types tools/test_np3.mjs
python tools/package_calibration.py
```

第一对文件真机通过后，再测试其余参数，建立 Nikon Flexible Color 的实际响应数据，随后拟合 CC/NC。NN 和理光两款仍需可核实的参考目标。
