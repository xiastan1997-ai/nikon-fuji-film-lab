# 拍摄与验收

## 最小素材包

先用现有 Z6III，不要求立即购买色卡或富士机身。首批需 6 个不同场景，每场景 RAW+JPEG，固定白平衡，同一设置拍 -1/0/+1 EV 三档。保留 EXIF，不经社交平台压缩。

若本机 DNG 转换仍无法读取现有高效率 NEF，下一批优先把“照片拍摄菜单 → RAW录制”设为“无损压缩”并拍一张 RAW+JPEG 配对用于解码验证；[尼康官方说明](https://onlinemanual.nikonimglib.com/z6III/en/psm_raw_recording_133.html)列出无损压缩、高效率m和高效率三种选项。此项只解决工具兼容性，不替代既有原片。

| 场景 | 关注点 |
|---|---|
| 日光人像 | 肤色、高光、红色唇部；取得被摄者同意 |
| 阴天街景 | 灰墙、中性色、砖红、天空 |
| 绿植 | 黄绿/蓝绿分离、饱和颜色 |
| 暖灯室内 | 肤色和中性物的偏色，记录灯源 |
| 夜景灯牌 | 高饱和颜色及通道截断 |
| 逆光/高反差 | 高光过渡、暗部与色彩漂移 |

有灰卡/色卡时加入画面用于曝光和白平衡校准。普通白纸只可提供有限中性参考，不能视为标定色卡。现场自动曝光/白平衡变化须记录，否则难以区分配置问题和拍摄变化。

## 两类参考分开收集

1. 官方 LUT 数学参考：合成测试值及颜色契约，不需要富士机身。
2. 富士原机外观参考：指定机型和固件、胶片模拟、动态范围、WB/偏移、曝光、锐度、降噪、颗粒、Color Chrome 等设置；同光线/视角/时刻拍摄 RAW+JPEG。无这类素材时，不声称完成富士原机复刻。

照片和 N-Log 视频另设实验；不要为了测试照片先录视频再抽帧替代。

## 数据登记

每个原文件在 `data/manifests/captures.csv` 一行：唯一编号、原始相对路径、SHA-256、相机/固件、场景、曝光、WB、优化校准、色调模式与训练/留出归属。未知字段保持空白，状态写 unknown；不得凭文件名补事实。

首轮将前三类场景用于拟合，其余三类作为留出；扩大样本后按场景重新划分。小样本仅判断是否值得继续，不能得出普遍适用结论。

## 比较方法

- 数值：同源测试的 RGB 误差、灰轴漂移、渐变连续性、域外/截断比例。色卡可报告统一显示参照白点和空间下的 ΔE00，分列中位数、P95、肤色与绿色；不混用场景线性数值与显示 Lab。
- 视觉：固定显示色彩设置、同尺寸同曝光比较，遮住方法名称；分别评“接近参考”和“个人喜欢”，避免把审美当准确度。
- 两机实景：不要直接做逐像素 RMSE；镜头/位置/噪声会干扰。对齐后比较稳定色块、区域分布与视觉结果。
- 机内：同一 NP3 在 NX Studio 和 Z6III 拍摄输出分别记录。参数、文件和环境版本一致后仍需看真实差异。

所有分数表先留空。相似度百分比不作为默认指标。最终需逐场景展示缺点与适用条件。
