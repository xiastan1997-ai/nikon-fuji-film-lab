Z6III 首次导入测试（目标固件 C 2.01）

这两个文件用于确认相机可否读取本项目生成的 NP3，还不是富士/理光胶片滤镜。
PICCON01.NP3：LAB_NEUTRAL，中性基准。
PICCON02.NP3：LAB_SAT_P20，在基准上仅将饱和度加 20。

1. 解压后，把 NIKON 文件夹合并到存储卡根目录。若原卡已有同名文件，先备份再操作。
2. 最终路径应为：NIKON/CUSTOMPC/PICCON01.NP3 和 PICCON02.NP3。
3. 使用相机菜单指定的主插槽。
4. 菜单：照片拍摄菜单 → 管理优化校准 → 载入/保存 → 复制到照相机。
5. 分别存入两个空的 C 槽位，保留原有常用配置。
6. 固定白平衡和曝光，用两个配置各拍同一处蓝天/绿叶/彩色物体，保存 RAW+JPEG。

请记录：文件是否显示、是否能导入、是否正常拍摄、第二个配置颜色是否明显更浓。
若无法导入，记录相机固件版本、主插槽和屏幕提示。
已通过文件结构和参数回读检查；尚未经过 NX Studio 或 Z6III 真机验证。
