# 首轮执行记录（2026-10-24）

## 原厂参考已取得

- 从 [富士官方 LUT 下载页](https://www.fujifilm-x.com/global/support/download/lut/)下载 `gfx-eterna-55-3d-lut-v110.zip`。
- ZIP 大小 45,809,710 字节；SHA-256 `FEBFC7050999620651CA0CF162BF8B499970EF270B4DA632765B61B958CF7940`；ZIP 完整性检查通过。
- 同页关联白皮书本地副本大小 3,152,408 字节；SHA-256 `C77D1BDF159199ED9682375DF9F7A09EBBA5B03134220F4902D81B552BE7BD20`。
- 包内 F-Log2C/F-Gamut C 到 BT.709 的 33 和 65 网格均含 Classic Chrome（CC）与 Classic Neg.（NC）；**没有 Nostalgic Neg.（NN）**。这是本包的确切清单，不代表富士产品完全没有 NN 风格。
- ZIP 名称为 1.10；CC/NC CUBE 头内版本仍为 1.00。不能用 ZIP 版本推断每张 LUT 都变化了。
- `tools/inspect_official_luts.py` 完整解析两款的四张 F-Log2C CUBE，分别验证 33³/65³ 数据行、数值有限性，并以固定种子 10,000 个输入点比较 33/65 网格插值。P95 最大通道绝对差 CC 为 0.01034、NC 为 0.01063（归一化值）。这只评估网格差，不是尼康还原误差。
- 白皮书第 11 页给出 F-Log2C 对数曲线，第 12 页给出 F-Gamut C 色域坐标，第 13 页说明 LUT 应用于 F-Log2C/F-Log2 影像。需先构造符合该输入条件的 Nikon 图像，不能将相机 JPEG 直接当作 F-Log2C。

## RAW 实验结果

- 只在项目 `.vendor` 中安装 rawpy 0.27.1，未更改系统 Python。五个 NEF 的 `rawpy.imread` 均返回 `LibRawFileUnsupportedError`；没有完成传感器像素解码。
- 尼康 [NX Studio 1.11.0 下载页](https://downloadcenter.nikonimglib.com/en/download/sw/279.html)声明支持 Z6III NEF，但当前 Windows 版要求 Windows 11；本机为 Windows 10，故没有在本机安装最新版。
- 官方旧版 NX Studio 1.8 下载页和原始安装链接当前返回 404，不能再把它当作已可获取的 Windows 10 方案。
- Adobe [Camera Raw 支持列表](https://helpx.adobe.com/camera-raw/desktop/dng-and-file-formats/camera-raw-plug-supported-cameras.html)包含 Z6III；已通过 Adobe DNG Converter 16.5 完成五张实际转换和 RAW 马赛克读取，详见[第二轮记录](09_RAW转换与桌面预览.md)。
- 五张 NEF 内嵌预览目视均为同一类日光山湖场景，突出蓝天、水面、灰色山石；仅一张有人物背影，没有可评估的近距离肤色，也没有暖灯、夜景、高饱和人工光源。即使成功解码，也只能做小范围场景检查。
- 第一批四张 JPEG 另含紫色花朵/绿叶、户外人群和湖边鸟类，可作已渲染画面的视觉覆盖；它们与第二批 NEF 不同名、不能作为同一场景 RAW/JPEG 配对。

官方 CC/NC 参考已就绪；照片 RAW 解码已在第二轮打通，但输入色彩/曝光适配仍未标定，NP3 输出及五款真机验证均未完成。NN 和理光两款需要可核实的参考样本。GitHub 目录已加忽略规则，默认排除原始样片、官方包、第三方克隆及实验输出。
